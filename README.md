# 폭염 속 우리 동네 수업

폭염으로 인한 수업 시간 변경을 주제로 한 10분짜리 민주시민·세계시민 교육 게임입니다. 주민 네 명의 제안에 답하며 여덟 가지 후속 사례를 살펴보고, 모둠의 결정안과 공지를 작성합니다.

## 실행

`index.html`을 브라우저에서 엽니다. 웹에서 실행하려면 이 폴더를 정적 사이트로 호스팅합니다. 별도의 빌드나 서버 의존성은 없습니다. 진행 기록은 사용 중인 브라우저에 저장됩니다.

## GitHub Pages

저장소의 **Settings → Pages**에서 **Deploy from a branch**를 선택하고 브랜치를 `main`, 폴더를 `/ (root)`로 설정합니다. 배포 후 Pages 설정에 표시되는 주소에서 게임을 시작할 수 있습니다.
